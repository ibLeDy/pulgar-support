# pulgar-support

The public face of [Pulgar](https://ibledy.github.io/pulgar-support/): the
privacy policy, support, and the issue tracker for beta testers.

**The keyboard's source is not here.** It lives in a private repository. This
one exists so the privacy policy can have a public URL — App Store guideline
5.1.1(i) requires one linked both in App Store Connect and inside the app —
and so testers have somewhere to report things without being handed the code.

- `index.md` — the landing page, served by GitHub Pages
- `privacy.md` — the privacy policy, Spanish and English

Issues are for anyone using Pulgar. They are triaged here and fixed in the
private repository.
